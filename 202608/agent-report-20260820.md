- [SPADE: Self-Play in Adaptive Synthetic Executable Environments](https://arxiv.org/abs/2608.19197) — Bo Liu 等提出在自适应合成可执行环境中进行自博弈（Self-Play）的 Agent 训练方法，让智能体在动态生成的执行环境中自我对弈提升能力，为 Agent 强化学习提供新范式。

- [RTPO: Reverse-Turn Policy Optimization for Stabilizing Agentic RL Training](https://arxiv.org/abs/2608.18682) — 面向 Agentic RL 训练不稳定问题的"反向回合策略优化"，通过重新组织轨迹回合缓解策略坍塌，是 agent 强化学习稳定性的重要工程进展。

- [Eureka: Task-Conditioned Meta-Agent Orchestration for Scientific Discovery](https://arxiv.org/abs/2608.19047) — 提出面向科学发现的任务条件化"元智能体"编排框架，让多个专业 Agent 围绕科研任务动态协作（Alizer Wong 等）。

- [DocClaw: A Unified Agentic System for Intelligent Document Processing](https://arxiv.org/abs/2608.18685) — 统一的 Agentic 文档处理系统，将解析、理解、提取、生成整合为可编排的 Agent 流水线，面向企业文档自动化场景。

- [Beyond the Transcript: Detecting Covert Coordination in Latent Multi-Agent Communication](https://arxiv.org/abs/2608.19161) — 关注多智能体在"潜在空间"中的隐蔽协调（隐式通信）检测问题：即使不共享显式消息，Agent 也可能通过内部表征协同，对多 Agent 系统的可审计性提出新挑战（MIT 团队，含 Ramesh Raskar）。

- [SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents](https://arxiv.org/abs/2608.18852) — 面向长程任务 Agent 的"策略内技能选择"训练方法，解决长时程任务中技能调用的分布漂移问题。

- [Sanyu Studio: A Multi-Agent System for Art-Historical Narrative Construction](https://arxiv.org/abs/2608.18677) — 多智能体系统用于艺术史叙事构建，多个 Agent 分工完成史料检索、考据与叙事生成，人文学科 × Agent 的交叉探索。

- [Adaptive Memory and Reflection Multi-Agent System for Medical Question Answering](https://arxiv.org/abs/2608.19029) — 面向医学问答的自适应记忆与反思多智能体系统，通过记忆更新与反思机制提升医疗 QA 的准确性。

- [What is Missing from AI Post-Training AI: An Empirical Analysis](https://arxiv.org/abs/2608.19072) — 对 AI 后训练（post-training）环节的实证分析，探讨"后训练之 AI"范式缺失的环节，与 PostTrainBench 等 Agent 后训练基准形成学术呼应。
