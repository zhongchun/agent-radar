# Agent Radar

AI Agent 领域每日雷达 —— 由 Hermes Agent 自动生成，覆盖国内外 AI Agent 最新动态。

> Daily radar for the AI Agent ecosystem — auto-generated by Hermes Agent, tracking news, papers, open-source projects, and trends.

## 日报内容

每天北京时间 7:10 自动生成，报告分为六大板块：

- **一、国内动态** — 中国 AI Agent 新闻、产品发布、政策动态
- **二、国际动态** — 国外 AI Agent 新闻、技术突破
- **三、企业界** — 产品发布、融资、战略合作、商业化进展
- **四、学术界** — arXiv 论文、学术会议、研究成果
- **五、开源项目** — GitHub Trending、Star-History 趋势、新项目
- **六、趋势分析与预测** — 基于当天新闻的趋势总结和短期预测

每篇报告末尾附 Star-History 趋势数据和 PostTrainBench 基准排名。

## 信息来源

| 类型 | 来源 |
|------|------|
| 开源 | GitHub Trending, Star History, PostTrainBench |
| 国际媒体 | TechCrunch, VentureBeat, The Verge, Ars Technica |
| 社区 | Hacker News, Reddit, Product Hunt |
| 学术 | arXiv, Papers With Code, HuggingFace Daily Papers |
| 国内 | 量子位, 机器之心, 36氪, InfoQ |
| 官方 | Anthropic / OpenAI / Google DeepMind 博客 |

## 使用方式

报告存储在 `{YYYYMM}/` 目录下，文件名 `agent-report-{YYYYMMDD}.md`。

在 GitHub 上直接浏览：
```
https://github.com/zhongchun/agent-radar/blob/main/202606/agent-report-20260607.md
```

## 自动运行

通过 Hermes Agent Cronjob 驱动，无需手动操作：

- ⏰ 每天 7:10 自动搜索并生成
- 📂 自动分类保存到对应年月文件夹
- 🔗 Git commit + push 到 GitHub
- 📩 推送摘要到飞书 Home Channel
