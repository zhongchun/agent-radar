## 四、学术界 🎓

### 1. The Regression Tax：为什么技能会"帮倒忙" — 评测 LLM Agent 技能的双面性
**作者：** Darshan Tank, Baran Nama  
**机构：** 未注明  
这篇论文提出了"回归税"（Regression Tax）概念，通过对近 6000 次 Agent 运行的分析，揭示了添加 procedural skills 的隐藏成本——技能可能在未被调用的情况下就已改变了 Agent 的行为（skill description osmosis），甚至覆盖掉 Agent 原本正确的行为（grounding/verification displacement）。论文建议在评估 Agent 技能时，应将其净效应分解为增益和回归两部分。
[查看原文](https://arxiv.org/abs/2607.22520)

### 2. TRACE-ROUTER：面向 Agentic AI 的任务级自适应路由
**作者：** Ritik Raj, Souvik Kundu, Sarbartha Banerjee 等  
**机构：** 未注明  
提出了 TRACE-Router，一个任务级 LLM 路由框架。与传统 per-call 路由不同，TRACE-Router 在任务开始时一次性选择模型，并利用任务的终端奖励（综合考虑准确性和延迟）来更新路由策略。在 tau2-Bench 和 Terminal-Bench 上均取得了非支配 Pareto 前沿点。
[查看原文](https://arxiv.org/abs/2607.22465)

### 3. 企业 AI Agent 的动态能力范围控制
**作者：** Halil Burak Noyan  
提出了一个三源权限架构（Three-Source Permission Architecture），取代传统的静态凭证配置，实现企业 AI Agent 的最小权限动态控制，降低过度授权带来的安全风险。
[查看原文](https://arxiv.org/abs/2607.22445)

### 4. IDEAgent：用于科研创意生成的 Agentic Quality-Diversity 搜索
**作者：** Varun Gumma, Navonil Majumder, Soumitra Sinhahajari  
利用 LLM 驱动的 Quality-Diversity 搜索算法自动生成和优化科研创意，突破了现有系统仅能生成单一最优方案的限制，实现了多样化创意的并行探索。
[查看原文](https://arxiv.org/abs/2607.22375)

### 5. Agent 基准测试到底测了什么？—— Agentic AI 时代的协议有效性

系统评估了当前主流 Agent 基准测试的协议有效性，指出许多基准测试的分数提升并不代表真实的能力进步，而可能只是评测协议本身的偏差。这对整个 Agent 评测生态提出了重要质疑。

## 六、趋势分析与预测 📈

### 1. AI Agent 安全成为本月最热议题

### 2. 企业 Agent 管理平台进入爆发前夜
AWS 发布 Loom、微软推出 Agentic 安全系统、Agno 新增 AgentOSTools——这些信号表明，企业级 Agent 的全生命周期管理（部署、监控、治理、安全）正在成为一个独立的产品品类。**预测：** 2026 年 Q3 将有更多云厂商和创业公司进入 Agent 管理平台赛道，类似当年 Kubernetes 之于容器编排的角色。

### 3. 中国开源模型正在改写 Agent 基础设施格局
Kimi K3 被用于防御 OpenAI Agent 攻击、吴恩达发布 100% 开源桌面 Agent、SearchOS 开源多 Agent 框架——中国 AI 社区正在以"开放权重+开源框架"的组合策略，在全球 Agent 基础设施层建立影响力。**预测：** 中国开源 Agent 项目将在未来 6 个月内在 GitHub 上占据更多份额。

### 4. Agent 评测方法论面临根本性质疑
本周有多篇论文（The Regression Tax、Protocol Validity）对现有的 Agent 评测方法提出了系统性批评——技能可能帮倒忙、基准测试分数不等于真实能力。**预测：** 业界将加速从"分数竞赛"转向"行为分析"，更加关注 Agent 的可靠性、安全边界和异常行为检测。

### 5. 物理世界 Agent 成为新前沿
Anthropic 的 Project Pilot（无人机操控）、Enigma 的 7100 万美元融资（机器人操控）、国内超维动力与北大医疗的合作（具身智能医疗）——AI Agent 正在加速从纯数字领域向物理世界延伸。**预测：** "Physical Agent"将成为下一个融资热词，具身智能+Agent 的交叉领域将迎来新一轮资本关注。
