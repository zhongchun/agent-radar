提出 LedgerAgent 框架，为工具调用 Agent 引入结构化状态管理（Structured State），确保 Agent 在调用外部工具时遵守预设策略，防止越权操作和数据泄露。
- 来源：arXiv (2606.20529)

- 来源：arXiv (2606.20122)
- [查看原文](https://arxiv.org/abs/2606.20122)

### 3. Phoenix：多 Agent 安全修复 GitHub Issue
提出 Phoenix 系统，利用多 Agent 大语言模型协作安全地解决 GitHub Issue。多个 Agent 分工协作完成代码理解、修复和验证，显著提升 Issue 解决率。
- 来源：arXiv (2606.20243)
- [查看原文](https://arxiv.org/abs/2606.20243)

### 4. Agent 自我进化：边际优势累积驱动记忆型 Agent 自我提升
提出通过边际优势累积（Marginal Advantage Accumulation）驱动记忆型 Agent 自我进化，Agent 在每次任务中积累微小改进，长周期运行后性能显著提升。
- 来源：arXiv (2606.20475)
- [查看原文](https://arxiv.org/abs/2606.20475)

### 5. AI Agent 的高效概率验证
