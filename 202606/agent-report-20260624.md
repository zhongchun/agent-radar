- **核心贡献**：提出 NatureBench 基准，从 Nature 系列期刊的同行评审论文中提取90个跨学科科学任务，评估 AI 编程 Agent 是否能从「复现」走向「发现」。配套 NatureGym 自动化流水线为每个任务构建标准化容器环境，是首个系统性评估 AI Agent 科研发现能力的基准。
