## 四、学术界 🎓

### 1. Are We Ready For An Agent-Native Memory System?
**作者**：Wei Zhou, Xuanhe Zhou, Shaokun Han, Hongming Xu, Guoliang Li, Zhiyu Li, Feiyu Xiong, Fan Wu (上海交通大学)  
**arXiv**：[2606.24775](https://arxiv.org/abs/2606.24775)

从数据管理视角系统研究 LLM Agent 的记忆系统，评估 12 种记忆架构在 5 个基准上的表现。核心发现：没有单一架构在所有场景占优——效果取决于工作负载匹配度。对 Agent 记忆系统设计者具有重要参考价值。

### 2. The Hitchhiker's Guide to Agentic AI: From Foundations to Systems
**作者**：Haggai Roitman  
**arXiv**：[2606.24937](https://arxiv.org/abs/2606.24937)

全面的自主 AI 系统构建实践参考，覆盖从基本原理到生产部署的完整技术栈。这份"银河系搭车指南"式的综述有望成为 Agent 工程师案头必备参考文献。

### 3. Autodata: An agentic data scientist to create high quality synthetic data
**作者**：Ilia Kulikov, Chenxi Whitehouse, Tianhao Wu, Yixin Nie 等 (AI at Meta)  
**arXiv**：[2606.25996](https://arxiv.org/abs/2606.25996)

提出让 AI Agent 扮演「数据科学家」角色自动构建高质量训练/评估数据的框架。通过对数据科学家 Agent 自身进行元优化（meta-optimization），实现显著性能提升。Meta 在 Agent 数据生产方向上的重要探索。

### 4. When Lower Privileges Suffice: Investigating Over-Privileged Tool Selection in LLM Agents
**作者**：Kaiyue Yang, Yuyan Bu, Jingwei Yi, Yuchi Wang 等 (BAAI/智源)  
**arXiv**：[2606.20023](https://arxiv.org/abs/2606.20023)

研究 LLM Agent 的过度权限工具选择问题。发现 Agent 在有安全替代方案时仍频繁选择过度权限的工具，揭示了 Agent 安全中一个被低估的系统性风险。

### 5. PrivacyAlign: Contextual Privacy Alignment for LLM Agents
**作者**：Manveer Singh Tamber, Abhay Puri, Marc-Etienne Brunet, Perouz Taslakian, Jimmy Lin, Spandana Gella  
**arXiv**：[2606.21710](https://arxiv.org/abs/2606.21710)

将隐私对齐纳入 Agent 对齐框架，确保 Agent 决定分享哪些信息时匹配用户在特定上下文中的隐私偏好。Agent 时代隐私保护的新范式。

### 6. Plans Don't Persist: Why Context Management Is Load Bearing for LLM Agents
**作者**：Aman Mehta, Anupam Datta (Snowflake)  
**arXiv**：[2606.22953](https://arxiv.org/abs/2606.22953)

Snowflake 研究团队的实证发现：上下文管理（压缩/摘要/驱逐）对长周期 Agent 任务至关重要，而「计划」(plans) 在上下文管理中最容易被丢失。为 Agent 记忆和上下文设计提供了重要警示。

### 7. Constraint Tax in Open-Weight LLMs: Tool Calling Suppression Under Structured Output Constraints
**作者**：Fangzheng Li, Aimin Zhang, Chen Lv  
**arXiv**：[2606.25605](https://arxiv.org/abs/2606.25605)

研究 Agent 系统中「工具调用」与「结构化输出」(JSON Schema) 的交互。发现结构化输出约束会显著抑制开源 LLM 的工具调用能力——对需要同时进行工具调用和结构化输出的 Agent 设计具有直接指导意义。

### 8. Neglected Free Lunch from Post-training: Progress Advantage for LLM Agents
**作者**：Changdae Oh, Wendi Li, Seongheon Park, Samuel Yeh, Tanwi Mallick, Sharon Li  
**arXiv**：[2606.26080](https://arxiv.org/abs/2606.26080)

揭示了后训练中一个被忽视的「免费午餐」——进度优势（Progress Advantage）对 LLM Agent 性能的显著增益，为 Agent 后训练提供了新方向。

### 9. SAFARI: Scaling Long Horizon Agentic Fault Attribution via Active Investigation
**作者**：Chenyang Zhu, Jiayu Yao, Kushal Chawla 等  
**arXiv**：[2606.24626](https://arxiv.org/abs/2606.24626)

针对长周期 Agent 的故障归因问题，提出通过主动调查（Active Investigation）实现可扩展故障定位的 SAFARI 框架。
